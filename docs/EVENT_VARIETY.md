# Effect and zombie event variety

The existing Effect and Zombies results remain registered. Additional events give the button more distinct outcomes without increasing the size of the existing zombie group.

Lucky Blessing grants one positive effect, and Double Blessing grants two different positive effects. Bad Omen grants one negative effect. Mixed Fortune grants one positive and one negative effect. Durations and amplifiers are bounded for each effect; short effects such as levitation and poison cannot use the long durations of utility effects.

Baby Zombie Rush spawns three to five baby zombies. Armored Zombies spawns two to three chainmail zombies, occasionally holding an iron shovel. Undead Variety spawns three to five zombies selected from regular zombies, husks, drowned, and zombie villagers. These enemies use the existing outside lobby spawn helper and temporary hostile entity cleanup.

Every button press selects uniformly from the registered events that can run in the player's current pool. Without an active cube, this is the normal pool; Lucky and Unlucky Cubes temporarily restrict it to beneficial or harmful events. No event waits for a press milestone, and every eligible event has the same selection chance within its current pool. Falling TNT drops one primed TNT from five blocks above the player; the existing six TNT event can also occur on the first normal press. Internal loot pool weights affect items within a selected loot event, not which Random Event is selected.
