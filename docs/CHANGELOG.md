# Changelog

## 0.1.0-beta.1 - 2026-09-24

- Lucky and Unlucky Cubes now add independent, persistent five-use positive or negative event pools, with stacking charges, a compact synced HUD, and a brief rising 3D use animation on both loaders.
- Reduced Lucky Cube and Unlucky Cube to compact tabletop-die size in inventory, hand, and world displays.
- Added Lucky Cube and Unlucky Cube as separate creative tab items with compact 3D cube models and 32 × 32 pixel art textures.
- Random Button now selects uniformly from eligible registered events; individual event weights and rarity no longer affect selection. Loot pools retain their own item balance.
- Added operator test commands for fast button presses, random or named event activation, chat statistics, and registered event IDs on Fabric and NeoForge.
- Added three falling meteor events with compact 1-block, rounded 3-block, and rounded 5-block stone impacts outside the lobby.
- Replaced Homing Star with a smoothly steering wind charge that deals light damage and knocks the target upward and sideways without damaging blocks.
- Removed overlapping direct inventory food, armor, and gear rewards so their thematic firework loot events are the only ordinary reward paths.
- Removed press count unlocks and the guaranteed 100th press event; all outcomes, including six TNT, can occur on any press.
- Added more event types from the first press, including falling TNT.
- Added positive, negative, and mixed effect outcomes plus baby, armored, and mixed zombie encounters.
- Blocked recall sigil drops immediately from the hotbar and inventory menus on both loaders; restore it on respawn without waiting for the fallback check.
- Fixed duplicate recall sigils when moving the item through an open inventory or container.
- Added eleven thematic loot events with separate building, color, wool, food, resource, potion, armor, and equipment pools.
- Added decorative loot fireworks that release stacked items with gentle spread and no explosion damage.
