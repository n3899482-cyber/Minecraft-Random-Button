# Meteor events

The Random Button can select Small Meteor, Medium Meteor, or Large Meteor. Each is one registered event with the same selection chance as every other eligible event. Every meteor lands on ground outside the protected lobby.

Small Meteor leaves one block. Medium Meteor builds a rounded shape within 3 × 3 × 3 blocks. Large Meteor builds a rounded shape within 5 × 5 × 5 blocks. The shape uses basalt, blackstone, obsidian, and occasional magma blocks. Block entities and protected lobby blocks are never replaced.

Flame and smoke particles descend for 28 ticks before the stone appears. Impact particles and sound are cosmetic; the event does not create a real explosion or damage terrain beyond the meteor blocks themselves.
