# Minecraft Random Button (Beta)

Press the Random Button to trigger an unpredictable event in your Minecraft world. Outcomes range from useful loot and positive effects to hostile mobs, TNT, and falling meteors.

This beta release supports **Minecraft 1.21.1** on **Fabric** and **NeoForge**.

The project code is licensed under the [MIT License](LICENSE).

## Features

- Random events, including weather and time changes, mobs, effects, structures, TNT, and meteors.
- Lucky and Unlucky Cubes that change the pool of events for five uses.
- Themed loot events and a recall sigil.
- Operator commands for testing and inspecting events. See [test commands](docs/TEST_COMMANDS.md).

## Installation

Install Fabric or NeoForge for Minecraft 1.21.1, then place the matching mod jar in your `mods` folder. Fabric installations also require Fabric API. Use only one loader jar in a game instance.

## Beta

This is an early beta. Event balance and behavior may change, and bugs are expected. Back up important worlds before trying it. Please report issues with your loader, Minecraft version, steps to reproduce, and the relevant game log.

See [the changelog](docs/CHANGELOG.md) for this release's changes.
